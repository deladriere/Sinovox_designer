Connect Kraftor

  1. Use Chrome or Edge.
  2. Click Select port and choose the Kraftor USB serial device.
  3. The designer sends !INFO? and shows the Sinovox model, firmware and chip ID.
  4. Click Connect MIDI, choose the Kraftor MIDI output and select the channel set by the DIP switches.

Web Serial carries text and sentence-bank commands. Web MIDI carries voice changes and note triggers. Use Identify when several Kraftor units are connected.

Chinese/Pinyin and English text

Send ASCII Pinyin with tone numbers or English text. The firmware adds the active Sinovox language, pitch, speed, speaker and volume tags automatically.

ni3 hao3
suo3you3xi4tong3dou1zhun3bei4jiu4xu4
hello from sinovox

The maximum stored sentence is 200 ASCII bytes. If the module is speaking, the board replies !ERR busy; use !STOP to interrupt.

English → Sinovox Pinyin helper

  1. Enter English and click Translate. Supported desktop Chrome versions translate locally to Simplified Chinese; the first use may download a language pack.
  2. Review the Simplified Chinese.
  3. Click Make numbered Pinyin, then Use in speech box.
all systems are ready
所有系统都准备就绪
suo3you3xi4tong3dou1zhun3bei4jiu4xu4

If automatic translation is unavailable, click Google fallback, then paste only the Simplified Chinese result into step 2. The helper removes spaces and punctuation, lowercases the result and converts ü to ASCII v. Do not add [i1]; Kraftor adds the language tag.

Machine translation and automatic Pinyin can be ambiguous. Review names and polyphonic Chinese characters before saving important phrases.

Volume0–10CC 3[v]

Every change is stored locally. Pitch, speed, volume, voice and language changes apply to the next utterance; they do not alter speech already in progress. When MIDI connects, the complete current voice is transmitted. When serial is connected, changes are synchronized as:

!VOICE language pitch speed voice volume

Example default: !VOICE 1 5 5 0 10.

MIDI and DIP switches

DIP1–DIP4 are active-low binary switches with weights 8, 4, 2 and 1. All OFF selects Omni; values 1–15 select that MIDI channel. Reset Kraftor after changing the switches.

MIDI inputResult

RAM and FRAM sentences

  • RAM: 20 volatile slots, cleared at reset, MIDI notes 28–47.
  • FRAM: up to 100 persistent RC256 slots. MIDI notes 48–127 trigger slots 0–79; slots 80–99 remain serial/GUI only.

Every slot stores its own language with its text. Use the two-button EN | PY selector to choose English or Chinese/Pinyin before saving; the red button is the active language. MIDI-note and Play-button recall always use the slot’s saved language, independently of the current Voice language. Bulk paste assigns the current Voice language to all filled rows. Use Reload, Save all changed, per-slot Play/Erase or bulk paste. The printable reference sheet includes each slot’s language.
